## About

I'm a web developer focused on turning ideas into polished, usable software. I enjoy working across frontend engineering, developer tooling, automation, desktop applications, and security-focused projects.

- Building modern applications with **React, TypeScript, Vite, and Tailwind CSS**
- Developing **developer tools, file utilities, dashboards, and desktop software**
- Exploring **API security, Go, backend engineering, and CI/CD automation**
- Prioritizing **performance, accessibility, testing, privacy, and maintainable architecture**
- Learning through real projects and improving them iteratively
